# AutoFetcher

Chrome 擴充功能:在網頁上直接點選要追蹤的數值或表格欄位,設定抓取時間,自動累積成每日歷史,
內建 Report 頁檢視。支援需要登入的頁面(自動填入帳密),值異常時發通知。

## 建立第一個任務

1. 到目標網頁,**右鍵 → AutoFetcher → 選取要抓的內容**。
2. 頁面進入選取模式:
   - **點一下**加選那一格,**再點一次**取消(有沒有按 Ctrl／⌘ 都一樣);
     **Shift + 點**從上一格拉出矩形範圍,**拖曳**框選一片。點到另一張表是換表(可復原)。
   - **點欄標題**選整欄、**點列首**選整列;右上角工具列切「單格 / 整欄→一個值 / 整欄→每格 / 整列→一個值」(也可以按數字鍵 1～4)
     ——「一個值」是把整欄合成一個數字,「每格」是每一格各自一條紀錄。
   - **雙擊**、`Enter`、或右下角面板的**「完成」**都可以送出;`Esc` 或「取消」放棄。
     「一次建立多個任務」的群組選取裡,雙擊只加值,完成改按 `Ctrl／⌘ + Enter` 或面板的**「完成選取」**。
   - `Ctrl／⌘ + A` 全選這張表、`Backspace` 移除最後一項、`Ctrl／⌘ + Z` 或面板的「復原」反悔上一步。
   - `↑` 擴大到父層、`↓` 縮回。表格裡包小表格時,預設選到的是**你點的那一格**;
     監控頁那種「每一列都包一樣的小表」,在小表上選整欄會自動改成外層每一列的同一個位置,
     已選之後按 `↑` 或點別列的小表,值也會跟著換到外層。
   - 非表格的元素:點一下先鎖定(滑鼠移開也不會換),雙擊或 `Enter` 送出。
   - 右下角面板隨時說明選到什麼、已經選了幾個值、接下來可以做什麼。
3. 在瀏覽器右側開出設定面板:填任務名稱、抓取時間(可多個)、聚合方式(表格才有)。
   **表格每天新增一列(例如每日成交資訊)**的話,把「列定位」改成「最後一筆」,
   之後每次都會抓新的那一筆;最後一列若是合計,選「倒數第二筆」。欄也有同樣的設定。
   可按「立即測試」先驗證抓不抓得到,也可以順手加入儀表板。
4. 儲存。之後到點就會自動在背景抓,結果進 Report 頁。

同一頁要抓好幾張表或好幾個數字:右鍵 → **一次建立多個任務**,每張表點好、數字直接點,按完成後在面板幫每個任務取名,
共用抓取時間,「全部試抓」看過再「全部儲存」。

看不懂的地方:右鍵 → **使用教學**(可在報表的「設定」關掉這一項)。

右鍵 AutoFetcher 選單共五項:**選取要抓的內容**、**一次建立多個任務**、**設定此站台登入**、**開啟 AutoFetcher 報表**、**使用教學**。

需要登入的網站:先到**登入頁**右鍵 → **設定此站台登入**,在右側的設定面板裡依序點選
帳號欄、密碼欄、送出鈕,填好帳密存檔。之後抓取時若被導到登入頁會自動登入。

## 功能

- **選取**:四層選擇器(id/data 屬性 → 結構路徑 → 文字錨定 → XPath)依序嘗試,頁面小改不會立刻失效。
- **擷取**:數值(五種策略鏈與備援)、文字、**表格區塊聚合**(某一欄或某一列取 max/min/avg/sum/count,
  支援 `<table>`、ARIA 表格、CSS 假表格、清單;欄位搬家會靠表頭文字跟著走)。
  **位置定位**:表格每天在最前或最後新增一筆時,改用「第一筆／最後一筆／倒數第二筆」,
  每次抓取重算位置,不受會變動的日期標題影響。
- **排程**:每日多時段,或每 N 分鐘(對齊整點格線,可限定時段與星期);錯過的每日排程可補抓;看門狗定期自我修復;抓取前預檢提早示警。
- **登入**:站台帳密以 AES-GCM 加密存本機,連續三次失敗自動停用該站台;每日固定時間檢查一次。
- **告警**:值大於/小於/等於、與前一筆比變動幅度、連續失敗次數;同一條件 60 分鐘只通知一次。
- **報表**:儀表板(可自訂版面的七種卡片、自繪 SVG 圖表;編輯模式可把任務從側欄**拖進卡片**、拖到空白處建卡、拖出移除;
  表格卡片可自訂列軸標頭、欄序與時間容差合併)、歷史查詢(月曆、篩選、樞紐表、比較)、
  任務管理、設定;可匯出 JSON / CSV / 單一檔案的離線 HTML 報表。

## 安裝(開發模式)

> 設定畫面走瀏覽器的側邊面板,需要 Chrome／Edge **114 以上**
> (自動關閉面板需 141+;更舊的版本會退回原本的彈出視窗,功能不受影響)。

1. Chrome:`chrome://extensions`;Edge:`edge://extensions` → 開啟「開發人員模式」
   →「載入未封裝項目」→ 新安裝選本輪 `src/` 或經下方指令產生的交付目錄。
   既有安裝先確認目前載入路徑與擴充功能 ID；不要直接換路徑，否則可能建立另一個擴充功能身分。`publish/` 不會隨 git 更新自動同步。
2. 到目標網頁,右鍵即可看到 AutoFetcher 選單。

## 開發

```bash
npm install
npm test          # 跑目前測試集(測試數隨版本變動)
./run_smoke.sh    # 真實瀏覽器端到端(需 Chrome for Testing)
```

可用 `npm run package -- /path/to/new-delivery-directory` 從 `src/` 產生新交付目錄及 SHA-256 清單；已存在目錄會拒絕覆寫。升級前分別匯出設定與歷史，沿用原安裝位置更新並重新載入。

## 升級注意(0.22.0)

- multi 值修復／替換會等待持久化 ACK；回覆不確定時可重送同一操作。修復與替換保留舊歷史，使用者明確確認刪除任務仍會依既有行為連同歷史刪除。
- 編輯既有任務可直接試抓；試抓不寫正式紀錄、帳本、lastValues、health，也不改變登入停用或告警狀態。Picker 來源若在選取中改變會阻止提交並保留草稿。
- 報表卡片更新、抽屜套用、拖曳與復原／重做以最新 layout 原子寫入，避免復活已修剪來源。設定頁初始不讀歷史，切頁按需載入；儀表板篩選重用相同日期範圍的資料。

一般 Chrome 152 起已封鎖命令列載入擴充功能,煙霧測試改用 Chrome for Testing:

```bash
npx @puppeteer/browsers install chrome@stable --path "$PWD/.browsers"
```
