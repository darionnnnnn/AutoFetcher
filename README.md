# AutoFetcher

Chrome 擴充功能:在網頁上直接點選要追蹤的數值或表格欄位,設定抓取時間,自動累積成每日歷史,
內建 Report 頁檢視。支援需要登入的頁面(自動填入帳密),值異常時發通知。

## 建立第一個任務

1. 到目標網頁,**右鍵 → AutoFetcher → 選取要抓的內容**。
2. 頁面進入選取模式,操作跟平常用試算表、檔案總管一樣:
   - **點一下**選取那一格(選取會取代前一個),**Ctrl／⌘ + 點**加選或取消,
     **Shift + 點**從上一格拉出矩形範圍,**拖曳**框選一片。
   - **點欄標題**選整欄、**點列首**選整列;右上角工具列也能切「單格 / 整欄 / 整列」。
   - **雙擊**、`Enter`、或右下角面板的**「完成」**都可以送出;`Esc` 或「取消」放棄。
   - `Ctrl／⌘ + A` 全選這張表、`Backspace`(或 `Ctrl／⌘ + Z`)移除最後一項。
   - `↑` 擴大到父層、`↓` 縮回。表格裡包小表格時,預設選到的是**你點的那一格**,
     要改抓外層那一格按 `↑`。
   - 非表格的元素:點一下先鎖定(滑鼠移開也不會換),雙擊或 `Enter` 送出。
   - 右下角面板隨時說明選到什麼、已經選了幾個值、接下來可以做什麼。
3. 跳出設定視窗:填任務名稱、抓取時間(可多個)、聚合方式(表格才有)。
   **表格每天新增一列(例如每日成交資訊)**的話,把「列定位」改成「最後一筆」,
   之後每次都會抓新的那一筆;最後一列若是合計,選「倒數第二筆」。欄也有同樣的設定。
   可按「立即測試」先驗證抓不抓得到,也可以順手加入儀表板。
4. 儲存。之後到點就會自動在背景抓,結果進 Report 頁。

需要登入的網站:先到**登入頁**右鍵 → **設定此站台登入**,在跳出的視窗裡依序點選
帳號欄、密碼欄、送出鈕,填好帳密存檔。之後抓取時若被導到登入頁會自動登入。

## 功能

- **選取**:四層選擇器(id/data 屬性 → 結構路徑 → 文字錨定 → XPath)依序嘗試,頁面小改不會立刻失效。
- **擷取**:數值(五種策略鏈與備援)、文字、**表格區塊聚合**(某一欄或某一列取 max/min/avg/sum/count,
  支援 `<table>`、ARIA 表格、CSS 假表格、清單;欄位搬家會靠表頭文字跟著走)。
  **位置定位**:表格每天在最前或最後新增一筆時,改用「第一筆／最後一筆／倒數第二筆」,
  每次抓取重算位置,不受會變動的日期標題影響。
- **排程**:每日多時段,或每 N 分鐘(對齊整點格線,可限定時段與星期);錯過的每日排程可補抓;看門狗定期自我修復;抓取前預檢提早示警。
- **登入**:站台帳密以 AES-GCM 加密存本機,連續三次失敗自動停用該站台;每日固定時間檢查一次。
- **告警**:值大於/小於/等於、與前一筆比變動幅度、連續失敗次數;同一條件 60 分鐘只通知一次。
- **報表**:儀表板(可自訂版面的七種卡片、自繪 SVG 圖表;編輯模式可把任務從側欄**拖進卡片**、拖到空白處建卡、拖出移除;
  表格卡片可自訂列軸標頭、欄序與時間容差合併)、歷史查詢(月曆、篩選、樞紐表、比較)、
  任務管理、設定;可匯出 JSON / CSV / 單一檔案的離線 HTML 報表。

## 安裝(開發模式)

1. Chrome:`chrome://extensions`;Edge:`edge://extensions` → 開啟「開發人員模式」
   →「載入未封裝項目」→ 選 `publish/`(或 `src/`)。
2. 到目標網頁,右鍵即可看到 AutoFetcher 選單。

## 開發

```bash
npm install
npm test          # 單元測試,基線 1643 綠
./run_smoke.sh    # 真實瀏覽器端到端(需 Chrome for Testing)
```

一般 Chrome 152 起已封鎖命令列載入擴充功能,煙霧測試改用 Chrome for Testing:

```bash
npx @puppeteer/browsers install chrome@stable --path "$PWD/.browsers"
```

## 升級注意(0.7.0)

- **選取模式的操作改了**:點一下從「選取並送出」改成「只選取」,送出改用雙擊、`Enter` 或面板的
  「完成」;加選從 `Shift` 改成 `Ctrl／⌘`,`Shift` 改成拉範圍。既有任務不受影響。
- **巢狀表格預設改取內層那一格**:外層那一格的文字是內層小表串接起來的
  (`25530` + `39806` 會被讀成 `2553039806`),要抓外層改按 `↑`。
- **整列聚合改成會跟著列標題走**:以前只認列的位置,表格前面插一列就靜默抓到別列;
  現在標題找不到會回報「找不到」並建議改用位置定位。**如果你的整列聚合任務抓的表格
  列標題每天會變(例如日期),請到任務設定把「列定位」改成「最後一筆」。**
