AutoFetcher 使用教學

在網頁上點選你要的數字，之後它會照時間自動去抓，結果都在報表裡。

  1. 選你要的數字在網頁上按右鍵，選「AutoFetcher」→「選取要抓的內容」，點那個數字。
  2. 設定多久抓一次按「完成」，在旁邊的面板選時間，按「儲存」。
  3. 看結果右鍵選「開啟 AutoFetcher 報表」。

這一版改了什麼

  • 任務管理可以勾好幾個任務，一起「改排程」、停用或刪除。
  • 已經選了好幾格時，Esc 要按兩次才會全部取消，不怕手滑。
  • 好幾個值想分開存，按「拆成每個值一個任務」。

我想抓一個數字

例如匯率表裡「美金 × 即期買入」那一格。

  1. 在那一格上按右鍵，選「選取要抓的內容」。
  2. 滑鼠移過去會出現橘框，點一下變藍框就是選好了。
  3. 按頁面右下角的「完成」。
  4. 在右邊面板選多久抓一次，按「儲存」。
遇到這些狀況
選錯了？
再點一次那一格就取消；或按面板上的「復原」、Ctrl＋Z。
不是表格裡的數字（例如頁首的總量）？
一樣右鍵選取，點那個數字；整個元素的文字裡第一個數字就是抓到的值。
面板沒有出現？
舊版瀏覽器沒有側邊面板，會改開一個小視窗。

我想抓一整欄

先想好：要一個總數，還是每一格各自記錄。

  1. 右鍵進入選取，把滑鼠移到那一欄的任一格。
  2. 要一個總數：右上角工具列點「整欄→一個值」。
  3. 要每格各一個值：點「整欄→每格」。
  4. 點那一欄任一格，整欄變藍框，按「完成」。
遇到這些狀況
「一個值」跟「每格」差在哪？
「一個值」把整欄加總（或平均、最大…，在面板選）成一個數字；「每格」是每一格各自一條紀錄，報表上是好幾條線。
合計列被算進去了？
在那一格按右鍵，選「從整欄聚合排除這一列」。只有網頁本來就把合計放在表尾區塊（tfoot）時才會自動排除；一般的「合計」列要自己排除一次。
開頭或結尾有幾列不要？
面板「抓什麼」裡有「略過開頭」與「略過結尾」可以填列數。
之後表格多了一列，會自動抓嗎？
「整欄→一個值」會（每次都算整欄）；「整欄→每格」不會，它記的是選取當下那幾格，新的那一列要重選。

我想在同一張表抓好幾個值

同一張表的幾格，存成同一個任務、一起抓。

  1. 右鍵進入選取。
  2. 一格一格點下去，點到的都會加進來。
  3. 點錯的那一格再點一次就取消。
  4. 按「完成」，在面板幫每個值取名字。
遇到這些狀況
想一次拉一大塊？
按住滑鼠拖曳框選，或先點一格再 Shift＋點另一格。
點到另一張表了？
一個任務只能抓同一張表。點另一張表會換成那張表（已選兩個以上時要再點一次確認），可以按「復原」。要兩張表都抓，用「一次建立好幾個任務」。
鍵盤操作
Enter 完成（只送已經選的，滑鼠停著的那格要先點）、Esc 取消（選了兩個以上要按兩次；面板或右鍵的「取消」也一樣）、Backspace 或 Delete 移除最後一個、Ctrl＋A 全選這張表、Tab 切換工具列。
選了很多格，認不出哪個是哪格？
滑鼠移到面板上的名稱，頁面上那一格會加粗標出來；點名稱會捲到那一格。
其實想分成好幾個任務？
按「完成」之後，在面板按「拆成每個值一個任務」，每個值會各自成為一個任務。

表格裡面還有小表格

例如監控頁每一列的某一格裡，又包一張小表。

  1. 把滑鼠移到小表裡你要的那一格。
  2. 要每一列的這個位置：工具列選「整欄→每格」或「整欄→一個值」。
  3. 點那一格，外層每一列的同一個位置都會變藍框。
  4. 只要其中幾列：用單格模式一列一列點。
遇到這些狀況
面板說「已改選外層表這一欄的同一個位置」
這是正常的：小表只有一列，所以自動幫你換成外層每一列。只要那一格就切回「單格」。
鍵盤 ↑／↓ 是做什麼的？
↑ 換到外面那一層表，↓ 回來。已經選了值時按 ↑，值會跟著換到外層（每一列都有同樣小表的時候）；值換到外層之後按 ↓ 不會回小表，要回去請先移除已選。
面板說「已選的值留在原表」
外層不是每一列都有同樣的小表（多半是排版用的表格），值不會跟著換；這時點外層的格子是換表。
重選既有任務時不能換到外層？
換過去之後歷史紀錄接不上，所以擋住了。要抓外層整欄請建立新任務。

同一頁一次建立好幾個任務

同一頁有幾張表或幾個數字要抓，一次選好、一次存。

  1. 右鍵選「一次建立多個任務」。
  2. 每張表點你要的格子，頁面上的數字直接點；不同的表會各自成為一個任務。
  3. 按「完成」，在面板幫每個任務取名。
  4. 設定共用的抓取時間，按「全部試抓」看看。
  5. 沒問題就按「全部儲存」。
遇到這些狀況
每個任務想要不同的設定？
多任務共用時間、去處與前置動作。先全部存好，再到報表的「任務管理」一個一個編輯。
要先點選單才出現的頁面？
在面板下方的「前置動作(套用到每一個任務)」加一步就好，這一批的每個任務都會照做；同一時間要抓時只會做一次。
存到一半失敗？
面板會說存好了幾個、哪一個失敗；已存的會從清單拿掉，修好再按一次不會重複建立。
內嵌在頁面裡的框架？
一批只能在同一個框架裡選。框架裡的內容請另外開一批。
最多幾個？
一次最多 20 個任務。

怎麼確認抓到了什麼

存檔前先試一次，看每一格有沒有算進去。

  1. 選完之後，在面板底部按「立即測試」。
  2. 面板會自動捲到「先試抓看看」，顯示抓到的值。
  3. 整欄或整列時，點「查看抓到的」看每一格。
  4. 表裡「採用」的才有算進去，其他會寫原因。
遇到這些狀況
立即測試過了，排程卻失敗？
立即測試用的是你眼前這個分頁；排程會自己另外開一份頁面。頁面要先點什麼才出現的，請加「前置動作」。
測試失敗，想請人幫忙看？
按「匯出診斷」存成檔案。檔案裡有那張表的內容與網址，給別人前先自己看一下。
編輯既有任務時沒有立即測試？
目前只有新建任務時有。

要登入才看得到

讓它抓之前自己先登入。帳號密碼只存在這台電腦。

  1. 打開那個網站的登入頁，在頁面上按右鍵。
  2. 選「設定此站台登入」。
  3. 填帳號密碼，帳號、密碼、登入鈕各按一次「在頁面上選取」。
  4. 按「儲存」。
遇到這些狀況
登入頁在另一個網域（例如用 Google 帳號登入）？
目前不支援，只支援同一個網站的登入表單。
有驗證碼？
無法自動登入。請手動登入並保持登入狀態。
密碼安全嗎？
密碼加密後只存在這台電腦的瀏覽器裡，不會同步到別台。匯出設定預設不帶密碼；要帶到別台電腦，匯出時勾選「包含站台密碼」並設一組密語。

要先點一下才會出現

例如要先點頁籤、關掉彈窗，數字才會出來。

  1. 先照平常把數字選好，打開面板。
  2. 展開「進階設定」，找到「前置動作」。
  3. 加一步「點擊元素」，按「在頁面上選取」點那個頁籤。
  4. 按「立即測試」確認，再儲存。
遇到這些狀況
滑鼠移過去才出現的選單？
用三步：「移到元素上」→「等元素出現」→「點擊元素」。
只靠 CSS 滑過去展開的選單？
程式送的滑鼠動作不是真的游標，打不開這種選單。通常選單項目本來就在頁面裡，把「等元素出現」的「要看得見」取消、直接點它。
點了之後整個頁面換掉？
沒關係，它會等新頁面載入再抓。

看報表與儀表板

每次抓到的值都存著，可以看趨勢、查過去任何一天。

  1. 右鍵選「開啟 AutoFetcher 報表」。
  2. 「儀表板」放卡片，新任務預設會加一張。
  3. 「歷史紀錄」查某一天或一段期間。
  4. 「任務管理」可以改名、改時間、停用或刪除。
遇到這些狀況
想一次改好幾個任務的時間？
在任務管理勾選它們（或按「全選」），按「改排程」，在面板設好時間後按「套用到 N 個任務」。只改一個的話，直接點那一列的排程文字。
只想改名字？
按名稱旁的「改名」，改完按 Enter。
想調整卡片？
儀表板按「編輯版面」，可以拖曳、改大小，點卡片開設定。
要把資料帶走？
歷史紀錄可以匯出；設定頁可以匯出匯入全部任務（密碼預設不帶，勾選並設密語才會帶出）。
不想在右鍵看到「使用教學」？
在「設定」關掉；那裡也留著開啟教學的連結。

圖示燈號的意思

瀏覽器工具列的圖示，一眼看出有沒有出問題。

  1. 沒有數字：全部正常。
  2. 黃色數字：抓到了，但有地方要留意。
  3. 紅色數字：有任務抓不到，點圖示看是哪一個。
  4. 灰色「II」：全部暫停中。
遇到這些狀況
黃燈常見原因
找元素時用了備用方式、表格只讀到一部分、補抓的紀錄、或要排除的合計列找不到。
紅燈常見原因
網站改版找不到元素、登入失敗、數字解析不出來、連續失敗。
想全部先停下來？
點圖示按「全部暫停 / 恢復」。

抓不到的時候

先試抓看原因，大部分都能在面板上直接修。

  1. 打開那個任務的網頁，確認數字還在。
  2. 到「任務管理」按重選，重新點一次那一格。
  3. 還是不行，建新任務時按「立即測試」，失敗就「匯出診斷」。
做不到的事
一個任務抓兩張不同的表
不行。一開始就用「一次建立多個任務」，每張表各一個任務。
多任務一次建立時，個別設定進階選項
不行（前置動作可以設，但整批共用一份）。先存好，再到任務管理一個一個編輯。
畫在圖表裡的數字
抓不到（那是圖片，不是文字）。
Shadow DOM 裡的元素
選不到（常見於用 Web Components 做的網站）。
比 1 分鐘更頻繁地抓
目前最短 1 分鐘。

右鍵的「使用教學」可以在報表的「設定」裡關掉；關掉之後，設定頁仍有開啟教學的連結。
